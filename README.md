# SUAMP - Server & URL Asset Management Portal

![SUAMP Dashboard](https://placeholder.svg?height=300&width=800)

SUAMP is a comprehensive web application designed to help DevOps teams and system administrators manage servers, URLs, and projects across multiple cloud providers. This centralized management portal provides real-time monitoring, cost tracking, and asset management capabilities.

## Features

- **Unified Dashboard**: Get a comprehensive overview of all your digital assets in one place
- **Project Management**: Track and manage projects with associated servers and URLs
- **Server Monitoring**: Monitor server status, performance, and costs across cloud providers
- **URL Management**: Track URLs, their status, and associated projects/servers
- **User Management**: Role-based access control for team members
- **Cost Tracking**: Monitor and analyze costs across cloud providers
- **Responsive Design**: Works on desktop, tablet, and mobile devices

## Technology Stack

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS
- **UI Components**: shadcn/ui
- **Data Visualization**: Recharts
- **Tables**: TanStack Table (React Table)
